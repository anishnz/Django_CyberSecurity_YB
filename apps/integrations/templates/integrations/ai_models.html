How the switching works

  1. The default model is tried first. Then the others that are on, smallest order number first. With equal numbers the agreed order is used: Gemini, DeepSeek, Claude, OpenAI, Other AI.
  2. If a model fails (429 free tokens or rate limit used up, 402 no credit, 401 wrong key, no internet, server down), the next one tries straight away.
  3. The result is saved on each model's row, so you can see which one is failing.
  4. Check sends one tiny question ("Reply with one word: OK") – it proves the key works and tokens are available. It uses a few tokens.

AI only writes drafts. A teacher checks the facts and the Kaiārahi checks Māori content. Student names are never sent to AI.
