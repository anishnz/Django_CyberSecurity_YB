Our story

CyberQuest started as an offline prototype for schools in Northland (Te Tai Tokerau). Teachers asked for safe, simple cyber-safety lessons that tamariki enjoy. The team rebuilt it in Django to add help desk tickets, email to whānau, certificates, business reports and integrations – while keeping the same kind, bilingual learning design.

This is a student project: {{ project.course }}, {{ project.college }}. Lecturer: {{ project.lecturer }}. Project code {{ project.code }}. The company, client, schools and students are simulated; all names in the demo data are made up.
