## Quick start (Windows)

1. Install **Docker Desktop** and start it.
2. Double-click **`run.bat`**. It finds a free port (8000, or the next free one up to 8020),
   creates `.env` with random secrets, starts Docker and opens your browser.
3. No Docker? Double-click **`run_local.bat`** (needs Python 3.10+).

Demo logins are listed at `/accounts/demo-accounts/` (only while `DEMO_MODE=1`).
